# NHF Servicios

Landing page desarrollada para **NHF Servicios**, una empresa dedicada al mantenimiento edilicio, obras civiles y servicios para industrias.

El objetivo del proyecto fue crear una presencia profesional en la web que permitiera mostrar los servicios de la empresa, exhibir trabajos realizados y facilitar el contacto con potenciales clientes mediante una interfaz moderna, responsive y de fácil navegación.

---

## 🚀 Características

- Landing page completamente responsive.
- Hero principal con imagen de fondo y branding de la empresa.
- Sección de servicios organizada por categorías.
- Galería de proyectos realizados.
- Visualización ampliada de imágenes mediante modal.
- Información de contacto completa.
- Integración con Google Maps.
- Navegación mediante scroll entre secciones.
- Dominio personalizado y despliegue en producción.

---

## 🛠️ Tecnologías utilizadas
